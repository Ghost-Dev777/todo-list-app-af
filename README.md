# Task Management System

A full-stack task management application built with the MERN stack (MongoDB, Express.js, React.js).  
The system allows users to create, organize, track, and analyze their tasks with authentication, filtering, and productivity analytics.

---

## Features

- User authentication (registration & login)
- Input validation for user data
- Create, update, and delete tasks
- Task categorization
- Task filtering by title and date
- Task completion tracking
- Progress statistics and completion percentage
- Analytics dashboard with task activity charts
- Notification reminders for scheduled tasks
- User profile management (update email, name, password)
- Responsive UI built with Tailwind CSS

---

## Core Functionalities

### Authentication
Users can register and log in securely. Input validation ensures proper data formatting before submission.

### Task Management
Users can:
- create tasks
- edit tasks
- delete tasks
- assign categories
- set deadlines

### Filtering & Search
Tasks can be filtered based on title or due date to help users quickly find relevant items.

### Productivity Analytics
The system tracks task completion and displays:
- completion percentage
- monthly task activity
- comparative statistics

### Notifications
Users receive reminders when task deadlines approach.
